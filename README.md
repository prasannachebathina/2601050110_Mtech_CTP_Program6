# Student and Employee Data Model

## Aim
To implement Student and Employee data models using
traditional classes and dataclasses in Python.

## Concepts Used
- Python Classes and Objects
- Type Hints
- Dataclasses
- Object Initialization

## Description
The Student class uses a traditional implementation
with an __init__() method.

The Employee dataclass automatically generates
initialization and representation methods.

## Requirements
- Python 3.7 or above

## Execution
Save the program as main.py and run:

python main.py

## Output
Ravi 101
Employee(name='Priya', emp_id=201)

## Conclusion
Dataclasses reduce boilerplate code and make
data-oriented classes easier to implement.
